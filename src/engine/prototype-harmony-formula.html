Harmony scoring: which concrete formula?

The harmony decision (#217) fixed the shape: quality scores each connected formation symbolically — named-chord value plus a bounded tension/complexity term over deduplicated pitch classes. This demo puts a concrete formula on trial: which tension measure, which complexity measure, how the bound clamps — checked by marginal production on the formations that decide it. The decision's never-below-neutral floor is now on trial too: its main value may be punishing chromatic density, which a neutral floor forbids. Everything below is one simplified board: every pitch class you raise is a voice; all selected voices form one connected formation; register and octaves are invisible by design. Magnitudes are provisional tuning — react to the shape.

The shape on trial

voice factor = Π(1 + bonus) over the named instances it sings × Q
Q = clamp(1 + complexity − tension, 1, cap) — one per formation, over deduplicated classes

Tension weighs every pair of distinct pitch classes by interval class. Complexity pays per distinct class past the first. The clamp's shape is the question: the decided floor holds Q at or above neutral ×1.00 — tension can only cancel quality gains, never price density down. The free floor lets Q sink below neutral so chromatic mass is punished — and then the tension allowance becomes the compensation named value needs: every named formation gets A of its tension forgiven before the clamp, or lush sonorities pay their own instance bonuses back. A formation that names no chord stays at exactly ×1.00 either way — chord-sourced production only.

Formation & knobs
