# Breakthroughs preserve further progression cycles

Accepted balance direction, 2026-10-29; numerical tuning and implementation remain open.

Board breakthroughs should create room for the next cycle of meaningful investment and optimization. Pacing is judged against credited flow time and deliberate board optimization, with long-term progression the priority. The reported three-day run failed because it exhausted meaningful progression and reached numbers the game could no longer display, rather than merely making the player powerful.

Preserve exciting chord combinations and distinct module roles while constraining how broadly and indefinitely their effects compound. Ignoring discovered enemies remains possible but should become materially expensive; charge and combat must retain a recovery path. An undefeated enemy's pressure deepens with era-earned nous beyond its discovery threshold, so spending the wallet never weakens that enemy. Defeat removes its pressure. This amends ADR-0074's predictable penalty direction to allow progression-dependent pressure while retaining bounded, nous-only penalties. The exact curve requires tuning alongside the production economy.

The trade-off is deliberate: explosive combinations remain rewarding, but one breakthrough must leave further consequential choices. A larger number display alone does not establish a successful balance. The provisional validation horizon is 100 credited flow hours using the current planned layers; further layers or a longer horizon can follow later. An era may reach an effective ceiling where prestige becomes the productive next move and enables another breakthrough cycle.

The agreed cadence, revised 2026-10-30, is a first worthwhile prestige around 10 credited flow hours, validated against an 8–12-hour range, then roughly 5–10-hour eras. These are validation ranges rather than fixed timers. The longer first era gives players time to learn the board and experience several breakthroughs; useful purchases, new combinations, and meaningful placement decisions must sustain that time. Measure gaps between consequential decisions alongside prestige timing. Retained strength should shorten familiar territory in later eras, with most time spent developing the new frontier. Lasting module growth is bounded and establishes useful foundations across eras; mature modules retain meaningful trade-offs so placement and combinations still determine the strongest build.

Existing saves preserve practice history, module collection, merge tiers, and earned development. A rebalance may explicitly migrate or reset affected economy progress, with the adjustment explained and the original save backed up. Saves whose numeric state has already been lost receive a recovery reset rather than fabricated replacement currency. Exact migration boundaries require an implementation specification that distinguishes retained development from resettable economy purchases.

Chorus, Harmonizer, and modules with lasting growth are investigation candidates, not predetermined nerfs. The initial report's “Breather” meant a module whose name the player could not recall, rather than the timed break phase; the deployed Tail is a likely match. Exact coefficients, numerical representation, and migration mechanics remain implementation work. Validate candidate curves through progression simulations against the agreed horizon and cadence before treating tuning as established.
