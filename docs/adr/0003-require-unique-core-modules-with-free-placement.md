# Require unique core modules with free placement

The original accompanying-cell and gradual-placement decisions below are superseded by ADR-0007: all six core modules begin on an eight-cell board, with inactive modules reserving their cells. Free placement, required deployment, and board reshaping remain in force.

Enter/Exit Flow, Time, Habit, Goals, and Notes each become unique required modules when unlocked, keeping the grid tied to its focus purpose rather than letting players optimize useful focus tools away. Each required unlock includes an additional cell to preserve discretionary build space, and required modules can move to any unlocked cell during upgrade mode without a clustering requirement. Their optional focus features need not be used: sessions may be open-ended, habits or goals may remain unselected, and additional simultaneous goals come from upgraded slots in the single Goal module rather than duplicate modules.

Goal slots limit tracked goals, rather than selecting a gameplay subset from an unrestricted goal backlog, to limit overload and keep focus capacity tied to progression. Goals are practice conditions rather than concrete tasks. Tasks is a sixth unique required core module, unlocked progressively with the same free-placement and accompanying-cell rules; epic grouping remains a future possibility.

Task capture is unrestricted. Instead of limiting which tasks qualify through a selected task list, task rewards draw from a shared allowance earned by live session time, as described in ADR-0005.

Core-module uniqueness applies to deployment: duplicate core modules may appear in forge rolls and remain in inventory. Replacing a deployed core module happens atomically during upgrade mode so exactly one of each unlocked core type remains deployed.

Earned cell unlocks are banked and placed adjacent to an existing cell during upgrade mode; cells accompanying required modules use the same rule. Players may also reshape unlocked cells during upgrade mode, preserving total cell count and a connected final board, with a preview before applying the rearrangement. This preserves spatial strategy without making expansion placement irreversible.
