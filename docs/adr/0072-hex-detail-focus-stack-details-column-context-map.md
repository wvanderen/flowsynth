# The hex detail speaks in a focus-scaled stack, a details column, and a context map

The 2026-10-18 hex-detail interview found the issue-#388 composition drifting: an always-full-size Mutators face competed with the Modules face, the action rail floated mid-stage between face and chord column, profile grades showed bare letters with their authored coefficients hidden in tooltips, and the opened voice's place in the formation was nowhere. The cross-section now composes as three posts. The stack shows both layers always — Mutators above Modules, order unchanged — with one layer in focus at full scale and full engraving; the unfocused layer shrinks to an identity thumbnail (chassis, category rail, signature glyph, state marks — no text engraving; words and figures ride the tooltip). One action rail below the stack, its contents following the focused face (upgrade dial and button under Modules, slot unlock under Mutators), replaces the mid-stage rail column. One ruled details column beside the stack holds the standing facts in open sections — context map, profile, chord facts, mutator line — while the wave connections keep their breakdown disclosures: the column holds standing facts, not opened math.

The context map is a miniature of the whole in-range board heading the details column: owned cells shaded, the opened hex in the firm selected marker, its active chords drawn in their chord hues as center-to-center links between their voices — the board's twin edge lines fall inside one stroke at the miniature's scale, so the map draws the connection the chord is. It answers "where does this voice sit in my formation," and its owned cells navigate: click, Enter, or Space opens that coordinate's cross-section at the current face. No charge leads, no idle chords, no chip labels.

Profile-grade chips read the authored multiplier with the grade in parentheses — `×1.05 (A)` — wherever the shared chip renders (Hex detail, Forge candidate tiles, inventory inspection): the number is the fact, the letter the band it sits in. The chips are self-contained plain text; the tooltip disclosure they once carried was retired the same day — it restated the visible figure. Absent effects stay the bare `—`. The chord facts speak in the breakdown's ruled-row grammar — the capacity with its canonical mark, the total factor, the formation term with its quality scale drawn at column width — and the named instances list one per line beneath, hue-ticked: the reserved readout's panel-backed chips belong to its density, not to the ruled column.

Considered and rejected: keeping the rail beside each layer (it orphaned the actions mid-stage and forced the three-column grid that made the stage feel empty); a neighborhood-only context map (chords span the board, so cropping the board crops the answer). A fully static context map was the interview's first answer and was revised the same day by review: the map's owned cells navigate because the retired grid made cross-sections unreachable otherwise — the Return control and Escape still own dismissal.

Revised 2026-10-18 by the same-day review round: the context map's chord links and cell navigation, the chips' disclosure retirement, and the chord facts' ruled-row grammar recorded above; earlier drafts of this document carried the static map and the tooltip-bearing chips.

This records accepted direction from the interview; the phone sheet reflows the same posts — faces, actions, details, context map last.
