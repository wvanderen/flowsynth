# Breathers self-end, are pre-trusted, and pay per profile

The breather introduces the game's first production time that is neither flow practice nor upgrade downtime: an optional, timed break after a flow session closes. It is a distinct fourth mode, entered only after `endSession` has fully closed the session — record written, summary shown — so breather seconds contaminate neither the honesty machinery nor the session's practice accounting. It self-ends on a wall-clock allowance (the game's first auto-timed transition; the player is by design away at the end), and its time is pre-trusted wholesale: never provisional, never honesty-adjudicated, never practice credit. That exemption is the deliberate counter-image of the provisional pool — the honesty system exists to adjudicate *practice claims*, and a breather claims nothing, so there is nothing to ask.

The breather's bonus is authored per profile, not granted globally. A **breather response** comparable axis scales each oscillator voice's final ν/s while a breather runs, absent mark exactly ×1, graded like every axis — the game's established language for "this type is about X," and the only shape under which the planned breather-specialist roster means anything. Considered and rejected: a flat global multiplier on the nous rate (one tuning knob, but no module could ever specialize — a breather roster would be decorative) and a hybrid of global floor plus per-type response (two knobs over one effect). The board runs at full production during a breather — nous, charge delivery, forge progress — with every practice accrual excluded and the temporal clock advancing, so breathers drain reserves and hold Afterglow warmth instead of freezing it cold; a reset-to-zero clock was rejected for punishing exactly the boards the mechanic should reward.

Consequences recorded for the implementer: the mode union joins save validation; the per-voice term joins the allocation fingerprint so no stale chord solve survives the mode change; the offer rides the session summary and both endings (deadline, early exit) land in upgrade mode through one action; the completion line lands on the followed session's record, and the completed-count/seconds facts persist through prestige for the later roster and rebalance passes.
