Chord geometry on the FlowSynth board

Two ways a "named chord" could live on the hex grid, drawn with the same chords. Panel A is the distance-field board (pitch = hex distance from the carrier + 1 — the decided, prototyped law). Panel B is a Harmonic-Table-style isomorphic lattice (pitch fixed per cell, shape = chord, movable). Hover cells in Panel A to inspect pitch and neighbors.

A — Distance-field board

pitch = distance from the carrier + 1 · radius-6 board shown · toggle the chords
hover a cell…
Geometric law: neighboring cells always sit one ring apart, so adjacent synths' pitches always differ by exactly 1 — every chord is a consecutive run n : (n+1) : (n+2). The familiar minor triad 10:12:15 is geometrically impossible here (10→12 skips a ring); the minor-ish consecutive run is 5:6:7. Deep chords need deep boards: the major triad lives at rings 3·4·5 — and only there.

B — Isomorphic lattice (comparison)

pitch fixed per cell (octave-folded note names, schematic) · shape = chord, movable
C–E–G — the major-triad wedge: root + up-right (major third) + down-right (fifth)
G–B–D — the same shape, slid across the lattice: a new key, same chord class
What movable shapes cost: pitch becomes a property of where you buy, not how deep — the cell economy can no longer gate harmonic depth, and every chord class is available from the first ring. "The carrier as tonic" would need a new story too: on this lattice it anchors one key out of many, rather than tuning the whole field.
